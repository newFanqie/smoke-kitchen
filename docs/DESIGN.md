## 1. 玩家最终会玩到什么

玩家在世界中亲手建厨房、找食材、制作调料、处理原料、控制火候，再把做好的菜端到餐桌上。砧板上能看见正在切的菜，锅里能看见投入的食材；颜色、声音、蒸汽和烟共同告诉玩家当前状态。

核心体验是：**凭操作和观察把一道菜做好，逐渐从荒野小灶发展成一座有农田、畜舍、调料作坊和餐厅的厨房。**

真实性与可玩性采用以下原则：

- 操作过程真实：先处理食材，再进行煎、炒、煮、蒸、烤、炖、腌制和发酵。
- 烹饪结果真实：锅温、投料顺序、切块大小、加水、调味和翻动会改变成品。
- 时间经过游戏化压缩：一道家常菜通常在几分钟内完成，发酵可以在冒险期间进行。
- 美术保留 Minecraft 像素和方块语言，通过状态、动画、声音表达真实感。
- 普通厨房操作以准星交互为主。查看食谱、教程和配置可以使用界面。
- 提供可预测的规则与补救手段，让玩家能理解失败原因。

### 一次完整的做饭体验

玩家在河边找到野生水稻，收集种子带回种植；用陶锅煮米饭，在砧板上切葱，拿到鸡蛋后点燃灶台。炒锅预热，倒油，先炒鸡蛋，再加入米饭和葱花；根据滋滋声和米饭颜色调整火力、翻炒，最后用盘子分成两份蛋炒饭。

火太小会出水、口感湿黏；火太大又久不翻动会焦。中途可以减火、把锅移开，或补入适量米饭稀释过量盐。做完的菜可放到餐桌上，自己吃或与其他玩家分享。

## 2. 全局生存循环

**探索找种子与材料 → 农牧和采集 → 加工与调料生产 → 建造厨房 → 手工烹饪 → 食用、宴请与交易 → 获得新食谱与设备材料。**

内容之间必须产生联系：

- 新作物提供新做法，收获物也能用来繁殖动物或酿制调料。
- 新动物提供特定食材，普通家常菜仍能依赖原版农牧获得材料。
- 建筑提供可探索的厨房、作物样本、工具和食谱。
- 敌对生物守护额外奖励与探索地点；基础盐、油、酱油和主食均有和平获取路线。
- 后期设备改善批量生产、保存和操作便利性，手工厨房始终有价值。

## 3. 世界内操作

### 3.1 基础按键

| 场景 | 操作 | 世界内反馈 |
| --- | --- | --- |
| 摆放食材 | 手持食材右键砧板或容器，一次放入一份 | 食材出现在对应位置 |
| 切配 | 手持刀具右键砧板，每次完成一小段切配 | 刀具挥动，食材逐步分块 |
| 加调料 | 手持调料瓶或罐右键锅具，每次加入一标准份 | 倾倒动作、短促声音与简短文字提示 |
| 翻炒、搅拌 | 手持锅铲或勺右键锅具 | 食材移动、翻面或汤面搅动 |
| 调火 | 空手右键灶台正面旋钮区域，循环小、中、大火 | 火焰高度和燃烧声变化 |
| 装填燃料 | 手持有效燃料右键灶台燃料口 | 燃料存量可见 |
| 加水 | 手持水桶或水壶右键锅具 | 液面上升；桶或壶保留 |
| 盛菜 | 手持空碗或盘右键锅具 | 每次取一人份，锅内余量减少 |
| 取出物品 | 潜行右键可取出的食材、盘子或冷却锅具 | 空手取出；热锅有明确提示 |
| 查看详情 | 潜行并瞄准设备 | 显示简短的温度、份数和状态信息 |

同一物件的不同操作区使用碰撞位置区分，配合高亮和提示。触达困难时，设置中可改为整块交互并优先使用手持物品决定动作。

交互优先级固定为：手持工具的有效操作 → 当前瞄准部件操作 → 通用查看。单次输入只结算一次，不能同时触发主副手两次投料。左键保留原版挖掘与攻击习惯。

放锅、放蒸笼、加盖与开盖均是可见的世界操作。潜行持锅铲右键可颠锅，普通右键为翻炒；颠锅是一种更明显的翻动方式，首版不要求玩家凭鼠标轨迹做高难度动作。

### 3.2 避免操作变成重复劳动

- 切一份食材约 3～5 次有效动作，按住交互可按固定节奏连续切配。
- 切配时判定刀具、食材、砧板和玩家距离；任意高频点击都不能绕过动作间隔。
- 翻炒是有意义的间歇操作，正常烹饪不要求玩家持续疯狂点击。
- 蒸、炖、发酵可在放置后离开，设备通过外观表示状态。
- 手上物品不适用时只给提示，不吞食材、不误清空锅具。
- 手柄、按住操作和减弱屏幕晃动作为可访问性选项。

### 3.3 时间节奏草案

| 过程 | 游戏内实际等待起点 | 设计目的 |
| --- | --- | --- |
| 切一份菜 | 3～5次动作，约3～6秒 | 让切配可见，避免长时间重复点击 |
| 锅具预热 | 约10～20秒 | 留出备料与观察时间 |
| 简单煎炒 | 约45～90秒 | 有投料、翻动和出锅的决策空间 |
| 煮饭、蒸菜、烤制 | 约1～3分钟 | 可与其他菜并行准备 |
| 炖菜 | 约2～4分钟 | 适合文火等待与厨房分工 |
| 腌制、发酵 | 约1～3个游戏日 | 在种地、建造和探索期间推进 |

这些是调优范围。首次教学料理偏向短端，服务器可统一调整等待倍率。快速模式缩短等待，不改变投料顺序和失败规则。

## 4. 食材与真实烹饪规则

### 4.1 用“份”统一计量

食材以一件物品对应一份为基础。液体和调料也使用标准份数，玩家无需称克重。

- 小锅和小炒锅容纳最多 6 份主要食材；油、水、调味料另有合理上限。
- 大锅容纳 12 份主要食材；大份配方按比例增加产量。
- 食材、调料用量通过物件变化和简短提示可查。
- 食谱给出建议比例，允许少量误差。
- 所有容器具有真实容量，装满后继续点击会提示已满。

初始数值属于调优起点：一瓶油 8 次标准用量，一罐盐或干香料 16 次，一瓶酱油或醋 8 次。一桶水能给小锅注满一次，也可先灌入便于多次使用的水壶。用完的瓶、罐和桶保留，可再次灌装。

### 4.2 食材处理状态

| 状态 | 玩法影响 | 示例 |
| --- | --- | --- |
| 完整 | 处理快、烹饪较慢，适合整烤或炖煮 | 整土豆、整鱼 |
| 切片 | 熟得较快，适合煎炒 | 土豆片、肉片 |
| 切块 | 易于分份，适合炖煮、翻炒 | 萝卜块、肉块 |
| 切丝 | 受热快，容易过火 | 土豆丝、葱丝 |
| 剁碎 | 适合馅料，单独炒制容易散和干 | 肉馅、蒜末 |
| 去壳、去骨 | 获得可用原料和副产物 | 米、虾仁、鱼肉 |
| 揉制、发酵 | 使面团适合不同面食 | 面条、馒头、面包 |

处理方式由工具和食材决定；不同切法在食谱书中可选择默认方式，世界交互提示当前切法。初期不采用难以记忆的复杂按键组合。

### 4.3 热量与熟度

灶台产生热量，锅具升温，食材逐渐受热；投入冷食材或加水会影响锅温。关火后锅具仍有余热。

内部规则跟踪：锅温、食材熟度、水分、表面焦化、调味比例、混合或翻动程度。各食材保留自己的烹饪进度，避免最后加入的生肉直接继承前面食材的熟度。

玩家主要通过以下反馈判断：

- 油温低：流动慢、下料声音弱；合适：明显滋滋声；过高：开始冒烟。
- 食材：由生色变熟色，随后出现金黄、褐色、焦黑阶段。
- 汤锅：微热、微沸、沸腾；水少时蒸汽和声音改变。
- 锅底：久不翻动会局部焦化，不会把整锅瞬间变成同一状态。
- 实用温度计可提供温度范围；默认不要求玩家盯精确数字。

初期不做逐颗米粒或真实流体物理模拟。食材位置和翻炒动画服务于观察，烹饪结果由稳定、可解释的规则计算。

### 4.4 烹饪方法

| 方法 | 主要设备 | 玩家需要控制什么 |
| --- | --- | --- |
| 炒 | 炒锅、锅铲 | 预热、少量油、投料顺序、火候和翻动 |
| 煎 | 平底锅、夹子或锅铲 | 两面受热、翻面时机、油量 |
| 煮 | 陶锅或汤锅 | 水量、沸腾、投料先后和时间 |
| 炖 | 带盖汤锅 | 保持小火，等待食材软化，防止烧干 |
| 蒸 | 蒸锅、蒸笼 | 锅底水量、叠层、盖子和时间 |
| 烤 | 烤炉、烤盘 | 预热、温度、翻动和烘烤时长 |
| 拌 | 调理碗 | 原料处理、调味比例和混合 |
| 腌制 | 腌菜缸、密封罐 | 盐、水、原料比例与等待 |
| 发酵 | 发酵缸 | 前置加工、配料、密封与等待 |

### 4.5 菜谱与自由发挥

- 食谱是指导和命名规则。玩家未找到食谱，也可以凭正确操作做出对应菜品。
- 命名综合原料、比例、加工方式和关键操作判断；同一道菜允许合理替换。
- 达不到固定菜谱条件但原料可食、熟度合适时，生成“家常杂炒”“蔬菜汤”等通用菜，仍然能吃。
- 焦黑、严重过咸或夹生有明确外观和说明；轻微失误降低品质，严重失误才成为失败食物。
- 可通过加原料、加水、降低火力或提前盛出补救；已经烧成炭的部分不能靠加水恢复。
- 初期不加入精确营养、病原体、复杂交叉污染或一顿饭引发的长期疾病。

## 6. 工具、锅具与容器

| 类别 | 拟加入内容 | 差异 |
| --- | --- | --- |
| 刀具 | 石厨刀、铁厨刀、精制厨刀 | 耐久和切配效率提升；基础食谱均可使用低级工具 |
| 翻动工具 | 木铲、铁锅铲、汤勺、长筷、夹子 | 对应炒、盛、夹、翻面动作 |
| 面食工具 | 擀面杖、筛子 | 面条、饺子皮和面粉加工 |
| 锅具 | 陶锅、铁汤锅、炒锅、平底锅 | 容量、热惯性、擅长做法不同 |
| 配件 | 木盖、铁锅盖、蒸笼、烤盘 | 保温、蒸制、烤制 |
| 计量与搬运 | 水壶、油瓶、调料罐、实用温度计、隔热布 | 稳定加料与搬运热锅 |
| 餐具 | 木碗、陶碗、陶盘、汤盆、玻璃杯 | 单份装盛和多人共享 |
| 加工与保存 | 密封罐、陶罐、食物篮 | 携带和保存 |

厨刀只对生物具有普通工具级伤害，不把切菜工具设计成高收益战斗武器。用具只在有效操作时消耗耐久；空点不会损耗。

热锅移走后继续保留食材、温度和熟度。默认要求手持隔热布或先冷却；碰到热锅先给明确提示，烫伤设为可选难度规则。

## 7. 调料及完整获取途径

每种调料都要有生存可重复获取路线；建筑搜刮和村民交易是补充途径。

| 调料 | 原料来源 | 制作流程 | 主要作用 |
| --- | --- | --- | --- |
| 盐 | 海水或盐矿石 | 海边装取盐水后蒸发；盐矿经手磨加工 | 调味、腌制；两条路线互为替代 |
| 菜籽油 | 油菜籽 | 压榨，接入空油瓶 | 炒、煎和部分拌菜 |
| 猪油 | 普通猪或野猪的动物脂 | 冷锅小火熬透后装空罐，回收油渣 | 早期食用油替代，不依赖红石压榨机 |
| 芝麻油 | 芝麻 | 压榨，接入空油瓶 | 成菜点香，用量偏少 |
| 酱油 | 大豆、小麦、盐、水 | 蒸煮大豆，混合麦粉和发酵引子，发酵后过滤 | 咸鲜、着色；发酵缸提供分步提示 |
| 醋 | 米或其他谷物、水、醋引子 | 熟谷物制醋胚，发酵后过滤 | 酸味、部分腌制 |
| 糖 | 原版甘蔗 | 使用原版制糖路线 | 甜味；继续加热可制糖浆 |
| 辣椒粉 | 辣椒 | 晾干后手磨 | 干辣与香味 |
| 胡椒粉 | 胡椒果 | 成熟采收、晾干、研磨 | 肉类、煎鱼、浓汤 |
| 花椒 | 花椒灌木 | 成熟采收、晾干 | 麻味和炖煮香气 |
| 孜然粉 | 孜然籽 | 晾干、研磨 | 烤肉与煎制 |
| 葱花 | 葱 | 砧板切配 | 起锅点香 |
| 姜片、姜末 | 姜 | 砧板切配 | 煎、炖、蒸鱼 |

酱油流程是对现实工艺的游戏化简化，不用于指导现实食物制作。

### 盐水、引子和副产物的规则

- 普通水不产盐；海水取样仅在明确的海洋水域判定成功，容器名称显示“盐水”。
- 盐矿提供内陆早期盐源，不要求跨地图找海。
- 基础发酵引子可由熟谷物、菌菇和糖经过专用配方培养；醋引子有谷物发酵的初始路线。两者均可保留少量成品续种，也能从杂货摊购买。
- 引子是可见物品，有用途说明，不设置玩家必须猜出的隐藏步骤。
- 压榨残渣可作堆肥或部分动物饲料；谷壳可作少量燃料或堆肥；骨头沿用骨粉用途。
- 基础调料不会因为加工容器或引子本身缺少获取路线而形成循环锁死。

## 9. 新动物与养殖

| 动物 | 栖息地与行为 | 食材与其他用途 | 可持续获取 |
| --- | --- | --- | --- |
| 鸭 | 河流和湿地，成群游动 | 鸭蛋、鸭肉、羽毛 | 可繁殖、产蛋 |
| 鹅 | 湖边和农家，护巢时警戒 | 鹅蛋、鹅肉、羽毛 | 可繁殖；警戒行为不破坏玩家方块 |
| 野猪 | 林地，平时中立，受攻击反击 | 猪肉类食材、少量动物脂 | 可用根茎食物引诱，后期可圈养繁殖 |
| 河虾 | 清洁浅河，夜间更易观察 | 虾、虾仁 | 捕捞后可在适合水体中繁殖 |
| 河蟹 | 河岸与湿地，受惊躲避 | 蟹肉、蟹壳 | 可在围合水域养殖 |

原版鸡、牛、猪、羊、兔、鱼和蜜蜂保持核心地位。鸡蛋与鸭蛋等在普通食谱中通过“禽蛋”标签互相替代，特色菜才要求具体品种。

鸭可用谷物种子繁殖，鹅可用小麦或稻谷，野猪可用胡萝卜或土豆。河虾与河蟹的繁殖使用谷物饲料或海带，在足够水域和空间中低速进行；达到密度上限后停止繁殖，不在玩家水池里无上限增殖。运输水产可使用水桶，原版鱼类保持原版规则。

处理肉类使用原版可接受的表现尺度；不制作写实屠宰、开膛或血腥动画。

## 10. 新怪物与探索冲突

怪物内容围绕遗迹探索和食材保护展开，保持克制，避免把日常做饭变成持续防守。

| 敌对生物 | 出现场所 | 行为 | 奖励与限制 |
| --- | --- | --- | --- |
| 劫粮掠夺者 | 废弃粮仓、劫粮者营地 | 使用近战或投掷攻击，守护物资 | 掉落补给袋、少量调料或食谱线索；不远程抽走玩家箱内物品 |
| 地窖蠹虫 | 废弃酒窖、旧粮仓地窖 | 从遗迹中的特定腐朽容器或虫巢出现 | 掉落可堆肥材料和少量遗迹物资；不会污染或自动感染玩家厨房 |

暂不设计强制 Boss、怪物肉作为基础菜原料，或随机毁掉玩家农场的事件。后续若加入幻想食材和大型首领，单独作为扩展审阅。

和平难度下可照常探索相关建筑和取得普通物资；战斗奖励只提供便利、收藏和装饰价值。

## 14. 成品、用餐和保存

### 14.1 品质

成品先标明状态：夹生、可食、过熟或焦黑；在正常可食范围内，再分普通、可口、精制三级品质。

品质由熟度、调味、关键操作和食材新鲜程度决定。品质改善饱食和饱和度的效率，并可提供短时、温和的用餐效果。

- 热汤：短时舒适效果，避免强力瞬间治疗。
- 主食：饱和度较稳定，适合出门前准备。
- 精心烤制的肉类：较高饱和度，制作成本也较高。
- 多样菜品宴席：适合多人分享与完成成就，不强制玩家每天吃不同食物。
- 同类增益不无限叠加，连续食用不产生永久属性。

原版食物依然实用；模组食物的价值来自制作乐趣、资源效率、分享与适度收益。

### 14.2 餐桌与多人分享

- 菜可以装成单份带走，也可以放进共享菜盘或汤盆。
- 共享菜肴显示余量，食用一份后外观减少。
- 多人同时取餐时按实际份数结算，避免复制或最后一份被重复取走。
- 有容器的食物吃完返还容器；空容器可以直接重新使用。
- 默认不强制每顿饭后洗所有餐具。洗涤槽首先服务于食材加工、容器换装和可选的沉浸清洗。

### 14.3 保鲜与暂停

建议默认使用温和模式：容易腐败的食材和成品在世界实际运行约 7 个游戏日后降低品质，再经过较长缓冲期才变为不可食用；最终时长需实测。

- 干谷物、盐、糖和干香料不按生鲜速度变质。
- 冰柜显著延长保存期，腌制与晾晒提供不同保存路线。
- 默认不计算存档关闭期间的现实时间。
- 多人服务器持续运行时，保鲜按服务器游戏时间推进，即使某位玩家已下线；服主可选择关闭腐败或设置离线保护，具体策略对全服一致。
- 单人暂停菜单暂停游戏时，烹饪和腐败也暂停；多人游戏仍遵循服务器运行时间。
- 远离厨房不会停住保鲜计时。发酵、晾晒和腐败在返回时结算经过的游戏时间；加热设备暂不模拟未加载区块内的复杂连续加热，并在返回时给出清晰一致的状态。
- 区块未加载时，灶台、锅具、燃料和熟度一起冻结，不仅冻结其中一项。所有相关计时必须遵循这一规则，防止跨区块刷熟度或吞燃料。
- 可选择关闭腐败、延长保鲜期或启用更严苛模式。

保鲜是可配置的经营要素。默认不补算服务器或存档关闭期间的现实时间，持续运行的服务器应在开服设置中明确告知保鲜策略。

## 15. 学习、进度与经营目标

使用进度与食谱书引导，不设置无法解释的隐藏厨艺等级门槛。

| 阶段 | 玩家目标 | 自然解锁的体验 |
| --- | --- | --- |
| 荒野开火 | 泥灶、陶锅、石厨刀，煮一份饭或汤 | 基础切配、加水、火候 |
| 家常厨房 | 铁锅、炒锅、盐和油，完成炒饭与煎蛋 | 预热、翻面、调味 |
| 自给农家 | 建稻田、菜园和小型养殖区 | 连续获得食材和调料 |
| 调味作坊 | 压榨、研磨、腌制和发酵 | 酱油、醋、豆腐、泡菜 |
| 丰盛餐桌 | 蒸笼、烤炉、多个灶眼 | 多道菜协同制作、共享用餐 |
| 厨房经营 | 接村民订单、扩建储存与餐厅 | 菜品品质、批量准备、家具收藏 |
| 世界寻味 | 探索旅店、盐场、菌菇屋、遗迹 | 收藏食谱、地区风格装饰 |

订单要求类别、份数和最低品质，给出合理游戏内期限；初次接触可以无期限。奖励以绿宝石、种子、收藏装饰和设备材料为主，避免靠一份低成本食物无限刷资源。

食谱书可直接合成；成就解锁教程页与收藏记录。遗迹食谱是额外提示或纪念物，不能垄断基础菜的制作权。

## 16. 红石、兼容与多人规则

- 红石可控制灶台启停，比较器可读燃料、容器装载或加工进度。
- 漏斗可向明确的存储和加工设备输送原料；手工炒锅的投料和关键操作保持可见、可控。
- 后期可增加批量加工配件；自动加工能力以实际设备为边界，不默认一个漏斗就能代替所有厨师操作。
- 其他模组的米、番茄、禽蛋、盐等可通过标签接入；首次只保证原版和本模组闭环。
- 逻辑由服务器决定，客户端显示过程。多人可以分工切配、烧火、翻炒和上菜。
- 破坏有内容物的锅、打开容器、玩家死亡和存档重载，都必须保留或合理掉落实际材料，避免复制和吞物。
- 使用容器权限与领地兼容接口，不能绕过箱子或设备的访问保护。
- 不要求额外科技、能源、季节或大型前置模组才能完成主线。

## 17. 美术、模型、动画与声音清单

### 17.1 风格

采用接近原版的像素语言：清晰轮廓、有限色板、统一像素密度。原料和菜肴要在背包小尺寸下可辨识，锅具和家具通过少量方块体表现结构。

基础物品图标优先 16×16；确实难以辨认的复杂菜品可以评估 32×32，但同一类别保持一致。模型贴图尺寸根据 UV 展开决定，不能把整张贴图尺寸与物品图标尺寸混为一谈。

## 19. 必须通过的验收场景

1. 新建生存世界，无作弊获得泥灶、锅、刀、盐、油和基本食材，做出并吃到一份完整饭菜。
2. 对同一套原料，正确操作、忘记翻动和过量加盐能得到有区别且能解释的结果。
3. 先下的食材和后下的食材保留各自熟度，临时加生肉不会直接变成熟肉。
4. 半成品取出回锅、热锅移动、破坏设备、退出重进均不复制或丢失材料。
5. 多人同时加料、盛最后一份菜时，数量与容器始终正确。
6. 冰柜、晾晒、发酵、腐败和区块卸载遵循明确规则，离线不按现实时间惩罚。
7. 所有新增物品都有获取路线；基础生产链没有“必须先拥有成品才能生产第一份成品”的死循环。
8. 新建筑和生物在正确环境出现，生成密度不会挤占正常探索，旧存档有替代获取方式。
9. 关闭生鲜腐败、烫伤和复杂提示后，仍能保留主要烹饪玩法。
10. 单人普通厨房及多人多灶厨房运行流畅；远处或不可见设备不产生无上限粒子和重复声音。

## 20. 这版有意不纳入的内容

- 强制饮水、真实人体代谢、微量营养素或医学层面的饮食系统。
- 写实血腥屠宰、真实病原体培养或食品安全教学。
- 必须联网、购买素材或付费订阅才能烹饪的功能。
- 一次覆盖所有国家菜系、数百道菜与大量互不相关的生物群系。
- 完整电力工业、强制季节与必须击败 Boss 才能吃正常饭菜。
- 自动完成所有操作的万能厨房，以及日常随机毁坏玩家厨房的事件。

## 21. 请优先审阅的设计取舍

这些是本稿提出的默认方向，可直接改动，不是额外开工审批：

1. 菜系先以中式家常菜为主，搭配原版食材与少量烘焙。
2. 真实感集中在操作、火候、投料顺序和可见状态；保鲜温和且能关闭。
3. 新怪物围绕遗迹探索，基础调料和日常生产有和平路线。
4. 设备覆盖完整生活厨房，内容按完整一餐、厨房、农牧加工、世界经营的依赖顺序实现。
5. 匹配截图中的 26.1.2 / Fabric 环境，具体依赖兼容性在制作阶段验证。
