# 持续开发与验收清单

用户授权：持续完成已确认的设计稿，额度恢复后自动续做；每版亲自验证流程和画面，通过后上传 GitHub 并提供可安装开发版。每小时续做检查已在本聊天设置。不购买额度、不自动使用赠送或付费重置。

原则：优先继承和复用原版类、模型、材质、配方、粒子与容器交互。保持烹饪真实感：切法、先后顺序、锅温、水油、翻炒和独立熟度；不能将所有做法简化成熔炉等待。完成范围以 docs/DESIGN.md 的验收标准为准，不以“永远还有优化”无限延长工作。

## 后续按依赖完成

1. 完整生存获取与加工链、已实现菜谱的平衡和合理替换；已具备切法、投料时机、品质反馈、翻面与可关闭烫伤。
2. 清晰的个别原创物品、菜肴与动物外观。优先原版改造，不使用仅靠颜色和极小像素标记区分的雷同占位美术。
3. 农作物土壤/水域/地区、鸭鹅野猪养殖、蟹虾行为；和平模式的调料供应与可再生路线。
4. 九种探索建筑的独立蓝图和地区生成，避免只改摆设而结构相同。
5. 厨师/杂货商职业与交易、品质订单、食谱收藏和宴席进度；避免强制敌怪掉落作为基础调味料门槛。
6. 实际双客户端并发、掉落回收与搬运、存档迁移、关闭复杂机制的轻量玩法、长时间运行与性能验收；储存与区块卸载的保鲜时钟、锅里未分餐食物的制作时间起点仍须补全并验收，不能只凭玩家背包老化和冰柜测试判定完成。
