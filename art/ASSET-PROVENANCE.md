# Artwork provenance

`fried-rice-source.png` was generated with the built-in image_gen tool for this project on 2026-10-20. The same image is used by the fried-rice inventory model at `src/main/resources/assets/smoke_kitchen/textures/item/fried_rice.png`.

Prompt:

> Create ONE original game inventory item sprite for a Minecraft Java cooking mod. Subject: a shallow warm cream ceramic plate holding golden egg fried rice, small yellow egg squares and a few green scallion pixels. Single isolated object, three-quarter top-down view, centered, generous transparent margin. Strict low-resolution pixel art with an approximately 32 by 32 logical pixel grid enlarged by nearest-neighbor to the output size. Crisp square pixel clusters, hard pixel edges, limited 12-16 color palette, restrained upper-left pixel highlights, dark brown silhouette outline, readable at tiny inventory size. Cohesive with Minecraft vanilla item art, but original artwork. No lettering, no text, no labels, no grid lines, no UI, no shadow outside sprite, no realistic gradients, no blur, no anti-aliasing. Actual transparent PNG background. Asset use: egg fried rice inventory icon and mod icon. Do not draw any utensils, extra dishes, hands, faces or scenery.

The source retains the generator's native resolution. `tools/normalize-art.ps1` exports a transparent 64×64 texture using nearest-neighbor scaling and centered padding, with no artistic retouching. This is the first art asset, not a claim that every inventory icon, crop, animal and building already has final artwork. Other early assets currently reference vanilla textures. Minecraft textures and game files are not distributed in this repository.
