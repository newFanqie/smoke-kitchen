用户授权：持续完成已确认的设计稿，额度恢复后自动续做；每版亲自验证流程和画面，通过后上传 GitHub 并提供可安装开发版。每小时续做检查已在本聊天设置。不购买额度、不自动使用赠送或付费重置。

## 后续按依赖完成

1. 严格的菜谱切法、半成品、投料时机与操作提示；真实品质反馈、翻面/翻炒和可关闭的烫伤。
2. 清晰的个别原创物品、菜肴与动物外观。优先原版改造，不使用仅靠颜色和极小像素标记区分的雷同占位美术。
3. 农作物土壤/水域/地区、鸭鹅野猪养殖、蟹虾行为；和平模式的调料供应与可再生路线。
4. 九种探索建筑的独立蓝图和地区生成，避免只改摆设而结构相同。
5. 厨师/杂货商职业与交易、品质订单、食谱收藏和宴席进度；避免强制敌怪掉落作为基础调味料门槛。
6. 实际双客户端并发、掉落回收与搬运、存档迁移、关闭复杂机制的轻量玩法、长时间运行与性能验收。
