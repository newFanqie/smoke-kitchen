# 第一餐获取路线核对

此页是当前配方与获取代码的核对记录，尚未代替 DESIGN 第19节要求的“新生存世界无作弊从零做出第一餐”实机验收。此前客户端流程提供起始原料；下面的完整获取流程仍待实际跑通。

## 可按依赖推进的路线

| 阶段 | 获取与制作 |
| --- | --- |
| 原版工具 | 木材、圆石、工作台、石镐、熔炉、木炭或煤；沙子烧玻璃，黏土做陶锅与泥灶 |
| 早期厨房 | 泥灶：黏土球×4、木棍×1、圆石×4；陶锅：黏土球×5；砧板：橡木木板×3、木棍×2；石厨刀：圆石×2、木棍×1；手磨：圆石×6、木棍×1；木盖：橡木木板×2、木棍×1 |
| 种植 | 生存打草有概率掉模组种子，找到稻谷、葱和油菜籽种子，种在耕地并等待成熟；成熟收获有种子和2–3份作物，可重复种植。地区与水域规则尚待补全 |
| 米 | 稻谷放入手磨，空手操作，得到米与谷壳 |
| 盐 | 两块盐矿可掉四份盐矿石，手磨每份出四份盐晶；16份盐晶与一个空罐再研磨，得到一罐盐。空罐用玻璃×3、橡木木板×1合成，一次四个；海水蒸发是另一条来源 |
| 油 | 8份油菜籽与原版玻璃瓶在压榨机加工，得到一瓶8次用量的油和油渣；压榨机用橡木木板×7、铁锭×1、活塞×1。活塞依赖原版铁、红石、木材与圆石，无需先有油 |
| 早期猪油 | 普通猪额外掉落生动物脂；陶锅或平底锅从冷锅小火炼制，不加水油调味。2份脂肪装满1空罐（8次），1份装半罐（4次），返油渣；不需要压榨机或红石 |
| 量水 | 空水壶用铁锭×3、玻璃×2制作，瞄准水使用可灌满；每次给锅或调理、发酵等加工设备加1份水。米饭下米时需要1–3份水，不能直接把满桶6份水当成合适比例 |
| 第一顿米饭 | 陶锅嵌入泥灶，量水后下米，加燃料煮沸，转小火、加木盖焖至少10游戏秒并熟透，用原版碗盛出 |
| 蛋炒饭 | 炒锅需要铁锭×5、木棍×1；木铲需要橡木木板×1、木棍×2。原版鸡自然产蛋；葱在砧板切好。热油先下蛋，四成熟后倒入两份熟饭，最后下葱、盐，至少翻炒3次并熟透 |

配方依赖没有要求先持有盐、油或熟饭才能制作对应的第一套基础设备。具体生成距离、随机种子获取时间、各材料数量与容器返还仍须在实际生存流程中验收。

## 仍需处理和验证

- 目前种子统一从草丛随机获取；设计中的野生稻谷、水域、地区和土壤差异尚未实现。
- 压榨机需要红石活塞，第一瓶油的探索成本需要实际生存评估；不把依赖图无环当成节奏已经合理。
- 动物脂已补实际小火炼油、装罐和返油渣路线；矿盐、海盐、压榨、量水、脱壳和小火炼油已通过0.1.8原版与Iris客户端操作及存档恢复，具体范围见该版验证记录。
- 矿盐、海盐、压榨、量水和容器返还已有测试场景验收；仍需验证自然野生来源、成熟收获与完整无起始物资的一餐。
- 验收记录应写明世界种子、难度、行走路线与实际获得材料；不得通过生成原料、加速生长或设置熟度冒充无作弊完成。
