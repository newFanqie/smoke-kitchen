## 美术实际检查

检查了三套主要JAR中厨具、材质、食物与工具贴图，并沿乡野模型父级继续解析。农夫乐事样本的厨锅有4个部件、煎锅6个；森罗炒锅6个、汤锅11个；乡野炒锅6个、油锅8个，煎肉状态样本13个。部件少也能清楚表达用途，细节并不需要无限增加模型。

已看的农夫乐事材质多为16×16；森罗锅面和刀铲样本为16×16，汤锅与油壶使用32×32图集。乡野既有16×16材质，也有64×64或256×256图集；图集尺寸不能直接等同于每个方块面的像素密度。

可借鉴的美术规律是我们的设计判断：金属以深色锅腔、较亮锅沿和少量磨损色块区分层次；木器保留较宽的木纹和竹编节奏；食品通过轮廓、切面和聚集方式表达，而非所有菜都换一个颜色。圆形可用阶梯边界或少量允许的倾斜部件实现。美术参考不会改变Java继承复用共同逻辑的原则，也不把他人的贴图、模型或代码直接移入本项目。

烟火厨房现阶段仍有简化的食材类别模型与原版运行时材质引用，并未宣称已经完成全部独立美术。下一批原创样例应重点对比锅沿、刀铲、瓶型与一盘成菜，先检查原版渲染，再检查Iris；光影不承担掩盖基础轮廓问题的作用。

- [ATM10官方仓库](https://github.com/AllTheMods/ATM-10)有数据包、配置、KubeJS和任务组织，可参考统一配方入口、分阶段目标与兼容层。这里没有把网上某一版本的模组清单当作当前固定版本的精确内容，也没有复制其任务或脚本。
- [Cottage Witch作者站](https://cottage-witch.carrd.co/)通过任务教授厨房、自然与生活技能。可借鉴“做第一顿饭→独立作坊→餐厅”的教学节奏。
- [Farming Crossing 4作者页](https://www.curseforge.com/minecraft/modpacks/farming-crossing-4)把做菜、钓鱼、收集、出售饭菜与购买装饰相连。可借鉴有目标的食谱收藏和订单奖励，而非让食物只补饥饿。

## 有限扩展候选及顺序

下列为本项目设计建议，不是上述模组已核实功能的逐项复刻，也不是0.1.12全部已完成。

1. 先完成已确认的锅具接触、盖子遮挡、锅内切块、翻动和分阶段外观；将工具挂架、餐盘分享及可摆食材接入已有设备逐项验收。
2. 完成既定豆腐链：浸泡→磨浆→煮浆→过滤→点制→压模；现有短配方不能算完成。
3. 新增一组有独立操作的油炸样例：专用深油锅、漏勺提取与沥油，先选油条和炸物两条验收链；放在既定核心流程之后评估。
4. 蒸笼叠放、捣蒜/研香料、装瓶与挂架只在能提供明确新操作时扩展，不为相同等待过程再造一套机器。
5. 教学与经营沿现有设计推进：可固定的食谱/备料清单、基础订单、成菜收藏、节日宴席。节日候选先限粽子、月饼、早茶三组，不同时加入全部地方菜。
6. 大型厨房的共享收纳、可选批量备料与跨模组配方标签属于后期。每项须记录获取、操作、成品、回收、保存恢复和实际画面，未实现的条目保持待办。
