# Artwork provenance

`fried-rice-source.png` was generated with the built-in image_gen tool for this project on 2026-10-20. The same image is used by the fried-rice inventory model at `src/main/resources/assets/smoke_kitchen/textures/item/fried_rice.png`.

Prompt:

> Create ONE original game inventory item sprite for a Minecraft Java cooking mod. Subject: a shallow warm cream ceramic plate holding golden egg fried rice, small yellow egg squares and a few green scallion pixels. Single isolated object, three-quarter top-down view, centered, generous transparent margin. Strict low-resolution pixel art with an approximately 32 by 32 logical pixel grid enlarged by nearest-neighbor to the output size. Crisp square pixel clusters, hard pixel edges, limited 12-16 color palette, restrained upper-left pixel highlights, dark brown silhouette outline, readable at tiny inventory size. Cohesive with Minecraft vanilla item art, but original artwork. No lettering, no text, no labels, no grid lines, no UI, no shadow outside sprite, no realistic gradients, no blur, no anti-aliasing. Actual transparent PNG background. Asset use: egg fried rice inventory icon and mod icon. Do not draw any utensils, extra dishes, hands, faces or scenery.

The source retains the generator's native resolution. `tools/normalize-art.ps1` exports a transparent 64×64 texture using nearest-neighbor scaling and centered padding, with no artistic retouching.

In 0.1.1, `tools/voxel-art.mjs` authors the other inventory icons as editable pixel cuboid meshes, and authors distinct station geometry and crop growth models. These are native Minecraft JSON models, not AI-generated PNG files. Device inventory models inherit Minecraft's standard block display transforms. Material references point to Minecraft's runtime solid-color and block textures; no Minecraft textures or game files are distributed in the repository. The small generated fried-rice sprite is retained. Animal renderers still use vanilla models and skins and are not claimed to be finished original artwork.

In 0.1.2, kitchen tools reuse Minecraft item model parents (swords, shovels, hoe, shears, stick, bamboo, leather, cobweb and a clock frame) instead of the rejected tiny voxel tool silhouettes. The wooden lid inherits the vanilla trapdoor block model. Closed stove meshes reference the vanilla furnace burning face, animated campfire fire and soul fire textures; particles and sounds also use vanilla identifiers. The three gas-canister states are original cuboid meshes. Used/broken/stale/spoiled variants combine their base model with an original small state badge, while exact durability and gas volume remain stack data. No new raster artwork was generated for this version.

Iris 1.11.4, Sodium 0.9.2 and MakeUp Ultra Fast 9.6 were downloaded from their official Modrinth releases solely into ignored local test directories. They are not vendored, bundled or redistributed by this repository or its JAR. The gameplay screenshots show the actual client renderer. No third-party mod artwork was copied.

In 0.1.3, the existing vanilla references and original assets are retained. No new AI images or third-party assets were added. New recipe-flow screenshots are captured from the actual Minecraft client, including its ordinary world save and reopen flow.

In 0.1.4, the pot liquid surface is a small native Minecraft JSON model referencing the game's animated water_still texture, with a standard constant water tint. It uses the normal item model and submit pipeline; there is no custom shader or copied texture. Small native white-smoke and bubble particles display boiling and steaming. The pot-water item-model definition is a rendering resource, not another registered inventory item. No AI raster assets were generated in this iteration.
