# 第一餐获取路线核对

此页核对游戏中的正常生存获取依赖。用户2026-10-21已允许测试用代码提供基础材料、生成对应动物，不再要求测试玩家跑图采集；合成、击杀掉落、加工、切配、烹饪、食用和保存恢复仍由实际玩家操作验证。当前范围以DESIGN第19节的新说明为准。

## 可按依赖推进的路线

| 阶段 | 获取与制作 |
| --- | --- |
| 原版工具 | 木材、圆石、工作台、石镐、熔炉、木炭或煤；沙子烧玻璃，黏土做陶锅与泥灶 |
| 早期厨房 | 泥灶：黏土球×4、木棍×1、圆石×4；陶锅：黏土球×5；砧板：橡木木板×3、木棍×2；石厨刀：圆石×2、木棍×1；手磨：圆石×6、木棍×1；木盖：橡木木板×2、木棍×1 |
| 种植 | 河流、沼泽岸边找野生稻谷，平原找油菜、葱与其他蔬菜；成熟野生植株或耕地作物给2–3粒种子和2–3份原料。水稻耕地根旁两格内留同层或低一层水，缺水停长；作物可跨地区栽培。打草按当地生物群系补充种子 |
| 米 | 稻谷放入手磨，空手操作，得到米与谷壳 |
| 盐 | 两块盐矿可掉四份盐矿石，手磨每份出四份盐晶；16份盐晶与一个空罐再研磨得到满罐；4份盐晶与一个空罐可装4次用量的小批盐罐。空罐用玻璃×3、橡木木板×1合成，一次四个；海水蒸发是另一条来源 |
| 油 | 8份油菜籽与原版玻璃瓶在压榨机加工，得到一瓶8次用量的油和油渣；压榨机用橡木木板×7、铁锭×1、活塞×1。活塞依赖原版铁、红石、木材与圆石，无需先有油 |
| 早期猪油 | 普通猪额外掉落生动物脂；陶锅或平底锅从冷锅小火炼制，不加水油调味。2份脂肪装满1空罐（8次），1份装半罐（4次），返油渣；不需要压榨机或红石 |
| 量水 | 空水壶用铁锭×3、玻璃×2制作，瞄准水使用可灌满；每次给锅或调理、发酵等加工设备加1份水。米饭下米时需要1–3份水，不能直接把满桶6份水当成合适比例 |
| 第一顿米饭 | 陶锅嵌入泥灶，量水后下米，加燃料煮沸，转小火、加木盖焖至少10游戏秒并熟透，用原版碗盛出 |
| 蛋炒饭 | 炒锅需要铁锭×5、木棍×1；木铲需要橡木木板×1、木棍×2。原版鸡自然产蛋；葱在砧板切好。热油先下蛋，四成熟后倒入两份熟饭，最后下葱、盐，至少翻炒3次并熟透 |

配方依赖没有要求先持有盐、油或熟饭才能制作对应的第一套基础设备。实际生成与掉落另由生态和获取测试覆盖；制作链按用户允许的基础原料场景验收。探索距离与起步节奏仍未作完整平衡结论。

## 0.1.11当前制作场景

FirstMealFlowTest使用明确列出的基础材料、鸭猪与盐矿场景，实际合成原版工具与厨房、熔炉烧玻璃、击杀取肉和动物脂、研磨装盐、小火炼猪油、切丁两份鸭肉和两份番茄、取水加盖炖熟、盛汤食用并保存重开。制作链不发工具设备、加工产物或熟食，不改熟度；测试只为允许吃饭将饥饿值设为8。详细材料表、截图和验证范围见[0.1.11更新记录](UPDATE-0.1.11.md)。
