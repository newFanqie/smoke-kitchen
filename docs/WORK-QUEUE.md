# 持续开发与验收清单

用户授权：持续完成已确认的设计稿，额度恢复后自动续做；每版亲自验证流程和画面，通过后上传 GitHub 并提供可安装开发版。每小时续做检查已在本聊天设置。不购买额度、不自动使用赠送或付费重置。

原则：优先继承和复用原版类、模型、材质、配方、粒子与容器交互。保持烹饪真实感：切法、先后顺序、锅温、水油、翻炒和独立熟度；不能将所有做法简化成熔炉等待。完成范围以 docs/DESIGN.md 的验收标准为准，不以“永远还有优化”无限延长工作。
